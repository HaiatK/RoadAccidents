Project idea: Machine Learning-Based Road Accident Severity Prediction

Problem
Road accidents are a major public safety concern in Saudi Arabia. This project applies Machine Learning to predict accident severity and improve emergency response.

Dataset:
Source: Kaggle – Injured and Dead in Accidents
Size: 1152 rows, 20 columns
Includes accident details such as date, region, demographics, and number of injuries/fatalities.

Objective:
Build a multi-class classification model to predict accident severity (minor, serious, fatal), helping authorities prioritize emergency response.
